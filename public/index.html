Documentation

GET/api/rates
Returns the most recent exchange rates with 24h percentage change.
GET/api/rates?date=YYYY-MM-DD
Fetch historical data for any specific day. Example: /api/rates?date=2024-12-25
GET/api/rates?currency=USD
Get the current ZWG exchange rate for a specified currency. Options: USD, ZAR, BWP, EUR, GBP.
